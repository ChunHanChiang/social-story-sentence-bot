# 社會故事句型機器人

依照學生的年級、主角與情境，撰寫簡短、具體、貼近日常生活的社會故事；每句故事後標示所使用的句型。

## 使用方式

### ChatGPT 自訂 GPT

1. 下載本專案，開啟 `SKILL.md`。
2. 將 `SKILL.md` 中 YAML 區塊下方的指引全文複製到自訂 GPT 的「指示」欄位。
3. 儲存 GPT，並用年級、主角、情境等資訊開始對話。

### 支援 Agent Skills 的工具

將本專案資料夾放入該工具指定的 skills 目錄；若工具要求技能名稱與目錄名稱一致，請使用 `social-story-sentence-bot`。重新載入工具後即可使用。

> 不同工具的安裝方式可能不同。本專案提供可重複使用的指引內容，不會自動建立或發布 ChatGPT GPT。

## 提供故事資訊

可提供下列資訊：

- 年級或年齡
- 主角姓名
- 發生的情境
- 希望學生練習的行為（選填）
- 故事語氣或其他需求（選填）

例如：「六年級，小華，下課時和同學吵架，生氣時罵了不好聽的話；希望練習冷靜表達。」

## 句型標示

每句話後以括號標註：描述句、觀點句、指導句、肯定句、控制句或合作句。故事以描述和觀點句鋪陳，適度提供指導、合作及肯定句；句型比例依情境調整，通常每一句指導句搭配二至五句其他句型。
